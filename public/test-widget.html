Widget Test Page

Testing the Feedback Widget

This page is used to test the feedback widget functionality. The widget should appear as a button in the bottom-right corner of the page.

Features to test:

  • Widget button appears in bottom-right corner
  • Clicking the button expands the widget
  • Widget shows the survey form
  • Clicking the close button or backdrop collapses the widget
  • Widget is responsive and works on different screen sizes
