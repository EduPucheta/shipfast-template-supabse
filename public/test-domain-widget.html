How Domain Targeting Works

The widget system now supports domain-specific targeting:

  • All websites: Survey appears on any website with the tracking code
  • Specific domains: Survey only appears on matching domains/URLs

Domain Matching Examples:

  • example.com - Matches example.com and all subdomains (www.example.com, shop.example.com, etc.)
  • www.example.com - Matches only www.example.com
  • https://example.com/shop - Matches the specific page
  • localhost - Matches localhost (useful for development)

Testing Instructions

  1. Create a survey in the dashboard
  2. Choose "Specific websites or domains" for targeting
  3. Add the current domain shown above to the target domains list
  4. Set the survey as active
  5. Refresh this page - the widget should appear
  6. Create another survey with a different domain (e.g., "different-domain.com")
